## 1. 目标

为知识点和材料提供简单、可扩展的标签功能。当前可选标签为 `AI` 和 `Physics`；以后用户可在设置标签时就地新增其他标签。

## 2. 功能范围

- 知识点和材料可设置零个、一个或多个标签。
- 在知识点和材料的 UI 内直接选择已有标签。
- UI 提供“新增标签”输入，用户输入名称后自动创建并选中。
- 对已有知识点或材料的标签修改直接保存，不进入审核页。
- 知识点和材料列表可按标签筛选。
- 不提供独立的标签管理页。

## 3. 交互规则

- 默认选项只包含 `AI` 和 `Physics`。
- 新增标签名与已有标签或别名重复时，复用已有标签，不重复创建。
- 新增成功后，该标签立即出现在其他知识点和材料的可选项中。
- 标签选择与其他内容字段分开保存；其他内容仍遵循现有 Proposal 审核流程。

## 4. 验收标准

1. 知识点和材料 UI 中可选 `AI` 和 `Physics`。
2. 用户可同时选择多个标签，保存后立即在详情页生效，无需审核。
3. 用户可在同一界面输入 `Mathematics`；保存后标签被创建、选中，并出现在其他记录的选项中。
4. 应用中不出现独立的学科标签管理入口或页面。
5. 知识点和材料列表可按任一已有标签筛选。
