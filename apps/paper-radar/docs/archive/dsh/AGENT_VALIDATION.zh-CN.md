## 实现边界

- 宿主默认压缩器会在 `agent/request` 之外自行调用模型。目前仅对初筛 Agent 关闭该压缩钩子，在每轮检查整个累积上下文；超限时明确失败，保留已读取数量、工具记录和用量。不静默删去尚未考虑的知识。
- 使用一次性 Agent，并标记为宿主子任务。结束后释放活动资源；生产宿主仍可按自身持久化设置保存执行历史。业务结果独立保存。中断后的明确继续启动新尝试，按固定快照重新读取必要资料；没有实现原会话恢复或通用记忆管理。
- 新 Agent 提示词可编辑、预览、启用；普通单次提示词实验不能提供所需领域工具，因此提前提示改从日报发起新筛选。旧提示词实验保留。
- 重新判断一篇沿用原批次设置和知识快照；要采用新模型、新提示词或新知识范围，应发起新筛选批次。
- 真机触摸、多个供应商逐一真实调用、超大知识范围持续压缩及长时间系统睡眠恢复不计为已验证。
