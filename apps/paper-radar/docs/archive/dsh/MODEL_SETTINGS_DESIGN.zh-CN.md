# PaperRadar 模型设置：两套方案

主页面提供「快速省钱」和「深入分析」，均直接选择 DSH 已配置的模型，无独立账号或密钥。思考强度默认自动，可在卡片内展开调整。既有明确选择迁移时保留，不按方案名称擅自替换模型或降低思考强度。

默认每日初筛使用快速方案；单篇分析、独立研究总结、个性化联系、内容复核、论文讨论使用深入方案。高级设置可为每项任务选择任一方案或自定义模型与思考强度。上述选项只决定任务的启动模型，不规定阅读步骤，完整分析仍由一个自主 Agent 完成。

## 配置与优先级

配置 version=2，保留 revision、concurrency、tasks、fallback；新增 presets.fast/deep 和 assignments。服务端根据方案引用生成 tasks 的有效选择，旧任务保留创建时的模型快照。修改方案立即影响其引用任务的新请求，自定义任务保持独立。

优先级为本次明确选择 → 任务引用的方案或自定义选择 → DSH 会话／默认模型。v2 不再隐式从 single 二次继承，避免自定义任务受到无关设置影响。跨模型不能继承另一模型的思考强度，切换模型时界面恢复为自动。

旧配置将 screen 提升为快速方案、single 提升为深入方案；原有独立任务的覆盖项保留为自定义。配置首次加载进行兼容转换，保存时按新版本原子写入。继续支持旧客户端提交，并在服务端转换。乐观版本检查拒绝过期提交，模型与思考强度由 DSH 验证，包括当前无人引用的方案。

## 界面细节

- 下拉框显式渲染模型名称，不显示内部 JSON、厂商前缀或中括号。同名模型只在菜单辅助信息显示连接名，已选状态仍只显示模型名。
- 高级设置默认折叠，显示存在多少任务例外；包含逐任务覆盖、并行数量、备用模型、连接详情。
- 刷新连接保留未保存修改；提供放弃修改与保存状态。模型不可用、思考强度不支持或并行数无效时提示修正。
- 所有页面文案、任务名、思考强度、校验与操作错误均跟随界面语言。后台错误以稳定错误码映射，不直接向英文界面插入中文。
