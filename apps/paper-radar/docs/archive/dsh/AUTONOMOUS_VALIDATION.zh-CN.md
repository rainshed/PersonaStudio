# PaperRadar 0.3.0 自主任务改造验收

日期：2026-09-10。宿主：DSH 0.1.5-rc.1。本文对应本轮代码；此前 0.2.0 验收不代表新流程。

## 已实施

- DSH 模式的完整单篇分析使用一个 `single` Agent，报告仍有研究总结、推荐理由、材料联系和潜在交叉。旧的强制全文打包、分块提取、总结→个性化→独立复核→修订链退出该业务路径。
- 论文工具支持元数据、目录、分页阅读、搜索、参考文献、图注/表格文本；Persona 工具支持所选范围内的记录搜索、记录读取、文件与原文检索和续读。另有已有报告、话题历史、证据、笔记和结果保存工具。
- 输入是任务目标、语言/篇幅/严格度、论文元数据与摘要、范围和资料引用。模型决定工具选择、顺序、阅读深度和停止时间。六个总结栏目是现有交付格式，不是六个执行步骤。
- 每日初筛仍是一篇一个独立 Agent，统一并行数 N（默认 4，范围 1–16）。移除必须翻完知识分页、最多阅读两个章节、最多一次格式修改等旧流程门槛。实际阅读记录保留，可选工具访问失败成为来源限制，不再强制整个研究流程失败；任务失败和待确认不计为不推荐。
- 讨论按当前问题创建 Agent，历史通过工具读取，不再把完整历史与所有证据打包进请求，也不因历史超过 65000 字节而直接拒绝。提示词运行快照保存历史/报告引用，避免历史较长时快照保存反过来阻塞分析。
- `task-single/summary/connections/review/discussion` 提示词支持工具式工作台试跑，A/B 使用冻结的模板版本；初筛试跑从真实初筛记录取得固定资料。实验不会建立正式报告、修改日报决定或启用备用模型。修订可作为明确目标引用已有报告，不再自动安排修订模型。
- 单篇结果缓存只依赖本任务的模型/强度、目标、论文版本与元数据、解析器版本、Persona 身份/范围/版本和相关提示词。修改其他任务路由不使它失效。强制重新生成仍有效，旧报告和反馈保留。
- 已提交的有效组件、待核对候选、笔记及依据独立保存。后续失败或取消不会删除有效组件；明确重试创建新 Agent，通过已保存内容继续。没有伪称恢复原宿主会话。
- 认证仍由 DSH 管理，PaperRadar 只选择已配置模型和支持的思考强度。完整分析不再自动触发独立总结、材料联系或复核路由；界面解释这些偏好的生效场景。

## 验证

- Web 全量测试：252 项通过。覆盖原单篇/日报/自动调度/讨论/历史功能，以及自主提交、选择性结果复用、强制重做、部分结果保存与重试、晚到结果取消、超过 1 MB 的讨论历史、来源标识及哈希、真实续读 selector、A/B 模板隔离。
- 插件测试：6 项通过。TypeScript 检查、变更范围 lint、生产构建通过。
- 适配器测试通过真实 socket 回调验证 Agent、模型共享容量、取消清理和原生上下文整理计量。一次 Agent 请求加一次 compaction 耗尽两次预算后，后续调用被阻止；compaction 使用该任务选择的模型与强度，所有许可释放。
- 隔离真实 DSH + 已认证 Luna low + 受控论文/知识资料联调通过：每日初筛完成；带 Persona 的完整单篇分析 4 次实际模型调用，研究总结和个性化均可用；相同条件复用 0 次模型调用；锚点讨论 4 次调用后保存回答。
- 完整分析中模型自行选择的工具包含元数据、目录、知识搜索、正文读取、知识记录和参考文献；讨论中自行选择已有报告和论文/知识工具。没有通过测试专用指令强制完整分析的阅读顺序。

复现隔离联调（复用已有认证；临时模型选择不写入生产路由）：

```sh
node --experimental-strip-types scripts/verify-agent.mjs <DSH-node_modules> --autonomous
```

## 边界

- 当前图表接口交付图注与可解析的表格文本，不提供原生图像理解；没有把工具名当作图像能力证明。
- 原生 compaction 的路由和计量经适配器契约测试；真实模型联调没有刻意制造上下文溢出来触发压缩，因此不声称完成了真实长上下文压缩压力测试。
- Persona 接口有版本和范围约束；旧版本无法再读取时明确报错，不悄悄换成当前资料。实际阅读账本只证明工具交付过哪些内容，不证明模型理解了全部范围。
- 引用、结构、字数和原始用户事实由程序检查；不声称已完成科学正确性或全领域新颖性审查。
- 独立模式和旧提示词实验保留兼容实现；上述自主改造针对 DSH 业务路径和新增自主任务工作台。
- 没有批量重跑历史失败任务，没有新增前缀缓存或原文缓存系统，没有新增模型账号配置。

## 实现入口

- `paper-radar/web/server/dsh/autonomous-task.mjs`：任务目标、提交契约、选择性身份、提示词捕获。
- `paper-radar/web/server/dsh/research-tools.mjs`：按需读取、来源和实际交付账本。
- `paper-radar/web/server/analyses/autonomous.mjs`：完整分析、结果复用、保存与重试。
- `paper-radar/web/server/discussions/autonomous.mjs`：话题上下文和回答。
- `paper-radar/web/server/prompts/agent-experiments.mjs`：独立工具式试跑。
- `paper-radar-dsh-plugin/src/host-agents.mjs`：真实宿主 Agent、取消、预算及上下文整理计量。
