# 平台账号与模型选择

在「模型设置」中，认证保存在平台账号下，模型配置引用账号。同一账号可以供默认模型、筛选、总结、材料联系、讨论及备用模型使用，无需逐个认证。

## 使用方式

1. 点击「添加账号」，选择平台，填写 API Key，或保存后点击「登录账号」。
2. 在账号卡片点击「选择模型」。模型选择窗口只需要账号、模型和可选参数，不需要密钥。
3. 在「模型使用方式」设置默认模型；打开「按任务选择模型」后可分别设置。选择「选择其他模型…」可以直接从账号的平台目录选择新模型。
4. 测试某个模型会发起一次短文本请求并消耗相应平台额度。目录中的模型不保证当前账号都有访问权限。

ChatGPT / Codex 与 OpenAI API 是不同的接入方式，分别认证及计费。同一平台的不同账号也独立保存；自定义服务的地址、协议和认证方式属于账号配置。

移除模型只清理该配置及引用它的任务设置，不删除共享认证。断开账号认证会让其全部模型需要重新认证，任务选择保留。删除账号会清理其认证、模型和相关任务设置。界面会在后两项操作前说明影响范围。

修改已有模型配置会影响所有使用该配置的任务。只想修改某个任务时，应在该任务的选择框中选择另一模型。修改账号密钥、认证方式或服务地址会影响账号下所有模型；仅修改账号名称不影响认证。

## 数据与迁移

- 模型库 `settings.accounts[]` 保存账号公开配置；`settings.connections[].accountId` 引用账号。
- 加密库 `credentials[accountId]` 保存唯一凭据，OAuth 刷新读写通过同一串行事务完成，避免多模型持有彼此过时的刷新令牌。
- 账号配置变更会使旧模型请求的配置版本失效，旧请求不能读取新密钥、恢复断开的凭据或覆盖新状态。
- v1 加密库在服务启动时自动迁移到 v2。原库先复制到同目录的 `vault.v1.enc.bak`，随后原子写入迁移结果；第二次启动不会重新迁移。
- 旧连接各自迁移为账号，原连接 ID、任务引用和认证保留。不会根据平台名称合并已有账号；可以在迁移后的账号下继续选择其他模型。
- API 和浏览器只收到公开账号字段及是否保存认证的标记，不会收到密钥、令牌或内部配置版本。

## 本地接口

这些接口沿用同源、JSON 和 `X-Paper-Radar: 1` 校验。

| 接口                                   | 行为                                                       |
| -------------------------------------- | ---------------------------------------------------------- |
| `GET /api/models/config`               | 返回账号、模型、任务设置与脱敏调用记录                     |
| `POST /api/models/accounts`            | 新建/修改账号，可带 `apiKey`；留空保留同一认证范围内的密钥 |
| `POST /api/models/accounts/auth/start` | 用账号 `id` 开始授权，无需先选模型                         |
| `POST /api/models/accounts/disconnect` | 清除账号认证，保留模型和路由                               |
| `POST /api/models/accounts/remove`     | 删除账号及其模型，清理路由引用                             |
| `POST /api/models/connections`         | 保存引用 `accountId` 的模型配置；不能在此更新共享密钥      |
| `POST /api/models/remove`              | 移除单个模型，保留平台账号                                 |
| `POST /api/models/routing`             | 默认、任务及备用模型仍引用连接 ID                          |

原先不带 `accountId` 的连接保存接口保留兼容支持，不会按平台自动关联账号。授权步骤查询、回答和取消接口保持不变。

测试使用临时加密库、本地模拟模型服务及模拟授权流程，覆盖一次授权多模型、真实 Pi 适配器的共享 API Key 请求、并发刷新、撤销、权限失败隔离、旧请求失效与 v1 迁移；不会使用生产账号执行模型测试。
