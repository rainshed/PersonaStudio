# Ideas / 研究想法 · 交互原型

根据《PersonaStudio · Idea 需求文档 v1.0》制作的独立页面演示。使用虚构研究笔记，无需模型账号或第三方连接，不读取或修改正式 Persona 工作区。

在仓库根目录运行：

```sh
python3 -m http.server 4178 --bind 127.0.0.1 --directory docs/prototypes/ideas
```

然后打开 <http://127.0.0.1:4178>。也可以直接在浏览器中打开 `index.html`；建议使用本地服务器以保证文件存储与复制功能可用。

可以体验：

- 只写标题的快速新建，以及可选的自由 Markdown 正文。
- 列表检索、四个维度的组合多选筛选、归档与恢复。
- 新颖性、实现难度、执行状态分别修改，显式保存与草稿恢复。
- 本轮失败、补充理由、撤销失败和重新开始，完整修订内容回顾。
- HTTP(S) 链接、本地文件（单文件 5 MB）、复用已有文件；资源名称、说明、排序和移除。
- AI 上下文预览与复制，可选择是否包含资源信息。
- 多页面修订冲突提示、键盘操作和窄屏列表 / 详情切换。

快捷键：`N` 新建，`/` 搜索，`⌘ / Ctrl + S` 保存。

## 演示边界

记录、修订与草稿使用浏览器 localStorage；文件使用 IndexedDB。清理浏览器数据将删除演示内容。样例 Markdown 附件为本地生成的虚构内容；GitHub 和其他外部地址为示例，并未抓取。

Markdown 使用自带的有限语法渲染器，HTML 作为文本显示，只生成安全的 HTTP(S) 链接，不加载正文中的图片。

这是供体验与讨论的页面原型，**不是 PRD 首版生产交付**。尚未实现正式工作区 Markdown / Source 存储、后台权限隔离、备份与恢复、索引及 schema 集成；没有改动现有应用或其数据。
