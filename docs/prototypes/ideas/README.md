# Ideas / 研究想法 · v1.1 交互原型

根据《PersonaStudio · Idea 需求文档 v1.1》更新。使用虚构研究笔记，无需模型账号或第三方连接，不读取或修改正式 Persona 工作区。

在仓库根目录运行：

```sh
python3 -m http.server 4178 --bind 127.0.0.1 --directory docs/prototypes/ideas
```

新版：<http://127.0.0.1:4178/>。旧版对比：<http://127.0.0.1:4178/v1.0/>。

## 本次更新

- 新颖性、实现难度各有独立的可选说明，已有依据直接显示，也可暂不判断。
- 进度统一为未开始执行、执行中、已结束。
- 结束时明确选择成功完成、部分完成或放弃，并填写非空白简要说明。结果不默认代选。
- 取消结束不会改变正式状态；未完成的收尾输入在浏览器保存，可稍后继续。
- 已结束记录可修改收尾或重新开始。重新开始清空当前结束信息，历次结果与说明保存在历史中。
- 搜索包含两项说明和结束说明；支持结束结果多选筛选。
- 修订历史和 AI 上下文包含对应版本的判断说明与结束信息。

原有的新建、Markdown、资源链接、文件上传取回与复用、归档恢复、草稿和修订冲突提示继续可用。

快捷键：`N` 新建，`/` 搜索，`⌘ / Ctrl + S` 保存。

## 数据与演示边界

新版采用独立的虚构示例和浏览器存储空间。旧版页面和它的浏览器记录、草稿及附件保留在 v1.0 入口；不自动把旧的失败或暂缓记录解释成新的结束结果。

记录和草稿使用 localStorage，文件使用 IndexedDB（单文件上限 5 MB）。清理浏览器数据会删除演示中的修改。链接只保存地址；不读取外部页面或上传文件内容。Markdown 使用有限语法的安全渲染器，HTML 作为文本显示，正文中的图片不自动加载；判断与结束说明按纯文本显示。

这是页面体验原型，尚未连接正式工作区的 Markdown / Source 存储、后端校验与权限、索引、备份或恢复服务，不等同于 PRD 的生产验收交付。
