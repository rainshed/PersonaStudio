# PersonaStudio v0.1.1

本版本加入可选的 Paper Radar 应用，改进审核体验，并加强安装、升级与故障恢复。

## 新增与改进

- 同一个安装器支持只安装 AI Persona，或同时安装 AI Persona + Paper Radar；之后可以补装或移除 Radar。
- 新增扩展页面、应用切换、Persona 连接与订阅引导，以及 Radar 研究数据的备份、恢复和诊断导出。
- 加快收件箱审核和反馈页面导航。
- 修复本地与远程 Codex 会话元数据较大时无法读取上下文的问题。
- 升级及失败回退会保留运行中的 Studio 端口，避免默认端口被占用时重启失败。

## 安装与升级

支持 macOS。首次安装 AI Persona，或从 v0.1.0 升级：

```sh
curl -fsSL https://github.com/rainshed/PersonaStudio/releases/download/v0.1.1/install.sh | sh
```

同时安装 Paper Radar：

```sh
curl -fsSL https://github.com/rainshed/PersonaStudio/releases/download/v0.1.1/install.sh | sh -s -- --with-paper-radar
```

升级保留已有工作区和上一版应用；移除 Radar 保留研究数据。升级到本版本后，可以使用 `personastudio update` 更新，或使用 `personastudio install paper-radar` 补装 Radar。

## 验证范围

发布流程验证应用、浏览器操作、两种安装组合，以及从真正的 v0.1.0 发布包升级。升级演练覆盖知识与偏好保留、原有 Hook 命令与 MCP 读取、Radar 补装/移除，以及新版启动失败后恢复旧版。自动验收不启动真实 Codex 会话，也不调用真实模型；模型账户仍需用户配置。
