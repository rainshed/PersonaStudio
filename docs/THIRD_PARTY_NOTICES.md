## Installed dependencies

Python dependencies are declared in the application's `pyproject.toml` and resolved by its `uv.lock`. The optional model runtime declares its Node dependencies in `src/ai_persona/model_runtime/package.json` and `package-lock.json`, including the pinned Pi adapter. Their installed distributions include the relevant license information. Preserve notices when repackaging any of these dependencies.

The source notes the model service's adaptation from the related Paper Radar implementation. This repository does not include a Paper Radar application. Sample persona material is maintained separately from vendored code and is described in the [Demo README](../apps/ai-persona/examples/demo-persona/README.md).

The legacy regression fixture's PDF is an original fictional document generated by the project, not a redistributed research paper. Its [fixture README](../apps/ai-persona/tests/fixtures/legacy-demo/README.md) records how to regenerate it.
